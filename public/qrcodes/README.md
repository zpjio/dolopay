# 个人收款码静态目录（开箱即用方式）

将您从支付宝、微信（或开启云闪付插件后的云闪付）导出的**个人收款码原图**直接放入本目录并按以下文件名命名，重启或刷新页面即可立即在收银台展示：

- 支付宝收款码：`alipay.png`（或 `alipay.jpg` / `alipay.webp`）
- 微信收款码：`wechat.png`（或 `wechat.jpg` / `wechat.webp`）
- 云闪付收款码（可选插件）：`unionpay.png`（或 `unionpay.jpg` / `unionpay.webp`）

> 提示：如果您更习惯在网页端可视化操作，也可以直接进入 DoloPay 管理后台的 **「收款码配置」** 页面上传原图；后台上传的图片会持久化保存在 `.data/qrcodes/` 目录，优先级高于本目录的静态文件。
